# งานที่ 1: ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น
### Patient Health Risk Assessment and Registration System

เว็บแอปพลิเคชันสำหรับการคัดกรองผู้ป่วยเบื้องต้นก่อนเข้ารับการรักษา คำนวณค่าดัชนีมวลกาย (BMI) ประเมินความเสี่ยงสุขภาพตามเกณฑ์มาตรฐาน และออกใบสรุปผลการคัดกรองทางการแพทย์เพื่อลดเวลาการทำงานของเจ้าหน้าที่หน้าร้าน พัฒนาด้วย **React** และ **Material-UI (MUI)**

---

## 1. คุณสมบัติตรงตามข้อกำหนด (Requirements Compliance)

### 1.1 การตรวจสอบความถูกต้องของข้อมูล (Input Validation)
- ตรวจสอบความถูกต้องของข้อมูลป้อนเข้าครบถ้วน: **ชื่อ-นามสกุล**, **เพศ**, **อายุ**, **น้ำหนัก (กก.)**, **ส่วนสูง (ซม.)**, **พฤติกรรมเสี่ยง**, **กลุ่มโรคประจำตัว**
- หากพบช่องว่างหรือค่าตัวเลขที่ไม่สมเหตุสมผล ระบบจะแสดงแถบเตือน **MUI Alert** แจ้งเตือนข้อผิดพลาดทันที พร้อมปฏิเสธการประเมินผลจนกว่าจะแก้ไขข้อมูลให้ถูกต้อง
- มีปุ่มกรอกข้อมูลตัวอย่าง (เสี่ยงต่ำ / เสี่ยงปานกลาง / เสี่ยงสูง) เพื่อความสะดวกในการทดสอบ

### 1.2 การคำนวณและประเมินระดับความเสี่ยง (Risk Assessment Logic)
- คำนวณค่า BMI ตามสูตรมาตรฐาน:
  $$\text{BMI} = \frac{\text{น้ำหนัก (kg)}}{(\text{ส่วนสูง (cm)} / 100)^2}$$
- จำแนกเกณฑ์ BMI สำหรับประชากรเอเชีย:
  - `< 18.5`: น้ำหนักน้อยกว่าเกณฑ์ (ผอม)
  - `18.5 - 22.9`: น้ำหนักปกติ (สมส่วน)
  - `23.0 - 24.9`: น้ำหนักเกิน (ท้วม)
  - `25.0 - 29.9`: โรคอ้วนระดับ 1
  - `>= 30.0`: โรคอ้วนระดับ 2 (อันตราย)
- ประเมินความเสี่ยงร่วมกับพฤติกรรมการสูบบุหรี่, การออกกำลังกาย, โรคประจำตัวเรื้อรัง และกลุ่มอายุ โดยจัดจำแนกเป็น 3 ระดับ:
  1. **ความเสี่ยงต่ำ (Low Risk)**: BMI ปกติ, ไม่สูบบุหรี่, ไม่มีโรคประจำตัว (`Chip color="success"`)
  2. **ความเสี่ยงปานกลาง (Moderate Risk)**: น้ำหนักเกิน/ท้วม, หรือสูบบุหรี่, หรือมีไขมันในเลือดสูง (`Chip color="warning"`)
  3. **ความเสี่ยงสูง (High Risk)**: โรคอ้วน, มีโรคเรื้อรังสำคัญ (เบาหวาน, ความดันโลหิตสูง, โรคหัวใจ, โรคไต) หรือสูบบุหรี่ร่วมกับน้ำหนักเกิน (`Chip color="error"`)

### 1.3 การแสดงผลลัพธ์ (Result Display & Summary)
- แสดงผลลัพธ์ผ่านหน้าต่าง **MUI Dialog** สรุปข้อมูลผู้ป่วย, ค่า BMI, ระดับความเสี่ยง และปัจจัยเสี่ยงที่ตรวจพบ
- แสดงข้อแนะนำการปฏิบัติตน (Health Recommendations) แยกตามระดับความเสี่ยง (ด้านโภชนาการ, การออกกำลังกาย, การปรับพฤติกรรม และการพบแพทย์)
- มีปุ่ม **"พิมพ์ใบสรุปผลการคัดกรอง"** สำหรับพิมพ์เอกสารใบรับรองผลคัดกรอง หรือบันทึกเป็น PDF ออกแบบด้วย Print Stylesheet จัดหน้ากระดาษทางการแพทย์พร้อมช่องลงนามเจ้าหน้าที่
- ระบบบันทึกประวัติการคัดกรองล่าสุดอัตโนมัติ (LocalStorage)

## 2. รายการ MUI Components ที่ใช้งาน (MUI Components Checklist)

| หมวดหมู่ | Components ที่ใช้งาน | หน้าที่ในระบบ |
| :--- | :--- | :--- |
| **Structure & Layout** | `Container` | กำหนดความกว้างหน้าจอ Responsive (maxWidth="lg") |
| | `Paper` | กล่องแบบฟอร์มและการ์ดเนื้อหา พร้อมมิติเงา Elevation |
| | `Grid` | จัดตารางแบบฟอร์มและคอลัมน์ Responsive |
| | `Stack` | จัดเรียงปุ่ม หัวข้อ และองค์ประกอบตามแนวดิ่ง/แนวนอน |
| **Inputs** | `TextField` | รับค่าชื่อ-นามสกุล, อายุ, น้ำหนัก, ส่วนสูง พร้อม Adornment |
| | `RadioGroup` / `Radio` | ตัวเลือกพฤติกรรมความเสี่ยง (การสูบบุหรี่ และการออกกำลังกาย) |
| | `Select` / `MenuItem` | กล่องเลือกกลุ่มโรคประจำตัว (Underlying Disease) |
| | `Button` | ปุ่มประเมินผลความเสี่ยง และปุ่มล้างข้อมูล |
| **Feedback & Displays** | `Alert` / `AlertTitle` | แถบแจ้งเตือนความผิดพลาดเมื่อกรอกข้อมูลไม่ครบถ้วน |
| | `Dialog` / `DialogTitle` / `DialogContent` / `DialogActions` | หน้าต่าง Modal แสดงใบสรุปผลการคัดกรองความเสี่ยง |
| | `Chip` | แสดงสถานะระดับความเสี่ยงด้วยสีสัญลักษณ์ (เขียว, เหลือง/ส้ม, แดง) |

## 3. วิธีการเปิดใช้งานบนเครื่องคอมพิวเตอร์ (Local Development)

```bash
# 1. เข้าสู่โฟลเดอร์โปรเจกต์
cd health-risk-assessment

# 2. ติดตั้ง Dependencies (หากเปิดครั้งแรก)
npm install

# 3. เริ่มต้นรันเซิร์ฟเวอร์จำลองเพื่อทดสอบ
npm run dev

# 4. บิลด์ไฟล์สำหรับ Production (อัปเดตโฟลเดอร์ docs/)
npm run build
```

## 4. วิธีการนำขึ้นแสดงบน GitHub Pages (Deployment Guide)

### วิธีที่ 1: ติดตั้งผ่าน GitHub Web (ง่ายที่สุด ไม่ต้องใช้คำสั่ง)
1. เข้าไปที่ [GitHub.com](https://github.com) แล้วกด **New repository**
2. ตั้งชื่อ Repository เช่น `health-risk-assessment` เลือกเป็น **Public** แล้วกด **Create repository**
3. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไปบน Repository
4. ไปที่เมนู **Settings** ของ Repository -> เมนูด้านซ้ายเลือก **Pages**
5. ในส่วน **Build and deployment**:
   - Source: เลือก **Deploy from a branch**
   - Branch: เลือก **main** และเลือกโฟลเดอร์เป็น **/docs**
   - กดปุ่ม **Save**
6. รอประมาณ 1-2 นาที จะได้รับลิงก์เว็บไซต์ เช่น `https://<ชื่อผู้ใช้>.github.io/health-risk-assessment/`

### วิธีที่ 2: ใช้คำสั่ง Git Push
```bash
git init
git add .
git commit -m "feat: ระบบลงทะเบียนและประเมินความเสี่ยงสุขภาพเบื้องต้น"
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/health-risk-assessment.git
git push -u origin main
```
จากนั้นเข้าไปที่ Settings -> Pages -> Source: Deploy from a branch -> เลือก `main` และโฟลเดอร์ `/docs` -> กด Save
